## 1. 总体处理流程

当前管线分成两层：

1. 样本层：先固定一张正负样本表，避免每次对齐都重新读取和抽样 `mrds.csv`。
2. 特征层：以后所有地球化学、重力、气象、地形和地质特征都对齐到这张固定样本表。

流程如下：

```text
00_check_environment.py
  检查路径、依赖、矿点表头

01_prepare_mines.py
  标准化斑岩铜矿点表

07_build_sample_table.py
  生成固定正负样本表，默认已有样本表时跳过重建

02_prepare_geochem2_nure.py
  清洗 NURE 再分析地球化学宽表

03_prepare_geochem1_usgs.py
  从 USGS 地球化学 Parquet 长表中筛选目标元素并转为样点宽表

04_prepare_gravity.py
  清洗 NOAA 重力网格和 Alaska 重力测站数据

05_spatial_align_features.py
  默认对固定样本表做最近邻和缓冲区统计，生成样本特征表

13_align_cmmi_gravity_derivatives.py
  接入 CMMI 重力派生 GeoTIFF 栅格和 shallow/deep gravity-source worms 点特征

11_align_terrain_geology.py
  接入 DEM 地形、断层距离/长度、CMMI 地质图类别特征

12_align_climate.py
  接入 TerraClimate 1991-2020 气候态月值和季节/年度汇总特征

06_quality_report.py
  输出缺失率、数值统计和基础图件

08_make_analysis_subsets.py
  从全域样本特征表派生 western_core 和 southwest_core 分析子集

14_make_environment_groups.py
  基于气候、地形和雪水当量生成气候/风化环境分组

09_make_model_dataset.py
  从分析子集生成避免泄漏的 baseline 建模数据集

10_train_baseline.py
  训练 Dummy、Logistic Regression、Random Forest、HistGradientBoosting baseline
```

## 3. 坐标和清洗规则

### 3.1 坐标系统

当前统一输出坐标为：

```text
EPSG:4326 / WGS84 经纬度
```

处理规则：

| 数据源 | 原始坐标 | 处理 |
|---|---|---|
| 矿点 MRDS | 经纬度 | 转为数值，过滤无效坐标 |
| 地球化学1 `tbl_geol` | 经纬度 | 转为数值，过滤无效坐标 |
| 地球化学2 NURE | NAD27，经纬度字段 `Lat_NAD27` / `Long_NAD27` | 通过 EPSG:4267 转 EPSG:4326 |
| NOAA 北美重力 | 经纬度 | 经度统一到 `[-180, 180]` |
| Alaska 重力 | 经纬度 | 转为数值，过滤无效坐标 |
| CMMI Gravity Derivatives GeoTIFF | WGS84 栅格 + `.tfw` | 用 world file 定位行列号，按样本经纬度取最近像元 |
| CMMI gravity-source worms | 经纬度点数据 | 用 BallTree 计算最近点和 5/10/25/50 km 半径统计 |
| DEM HGT | WGS84 1 度瓦片 | 按经纬度定位瓦片和行列号 |
| CMMI 断层 | 经纬度线数据 | 最近距离用局部等距投影计算 |
| CMMI 地质图 | 经纬度面数据 | 用点面包含关系提取样本所在地质类别 |
| TerraClimate | WGS84 全球网格 | 按样本经纬度提取最近网格点月气候态 |

所有经度统一到：

```text
[-180, 180]
```

### 3.2 负元素浓度处理

地球化学原始数据中存在负值。根据 `tbl_data_dictionary.parquet` 的 `qualified_value` 字段说明，带有 `<`、`N`、`L` 等 qualifier 的结果被表达为负值。这表示低于检出限、未检出或小于阈值，不是真实负浓度。

当前脚本处理规则：

```text
元素浓度 < 0 -> NaN
```

影响脚本：

| 脚本 | 处理 |
|---|---|
| `02_prepare_geochem2_nure.py` | 对元素列中 `<0` 的值置为 `NaN` |
| `03_prepare_geochem1_usgs.py` | SQL 中仅保留 `qualified_value >= 0` 的元素值 |

注意：当前版本未单独生成未检出比例特征。后续可以扩展 `nondetect_count`、`nondetect_rate` 等字段。

### 4.2 `01_prepare_mines.py`

输入：

```text
C:\Users\PC\Desktop\探矿气象数据集\mrds.csv
C:\Users\PC\Desktop\探矿气象数据集\矿点-工作表1.csv
```

处理逻辑：

1. 读取 `mrds.csv` 的表头。
2. 读取 `矿点-工作表1.csv`。
3. 如果矿点表第一行等于 MRDS 表头，则跳过该行；如果没有表头，则直接用 MRDS 表头赋列名。
4. 过滤无效经纬度。
5. 清理关键文本字段。
6. 从 `model` 字段解析矿床模型，生成 `models_parsed`。
7. 生成布尔标记：
   - `is_porphyry_cu`
   - `has_copper_commodity`
8. 添加 `mine_record_type = porphyry_subset`。

输出：

```text
data_intermediate\mines_porphyry.parquet
data_intermediate\mines_porphyry.csv
logs\01_prepare_mines_summary.json
```

| `latitude` / `longitude` | MRDS 原始字段，数值化并过滤 |
| `state` | MRDS 原始字段 |
| `commod1` / `commod2` / `commod3` | MRDS 原始字段 |
| `model` | MRDS 原始字段 |
| `models_parsed` | 从 `model` 解析 |
| `is_porphyry_cu` | `model` 是否包含 `Porphyry Cu` |

### 4.15 `10_train_baseline.py`

输入：

```text
outputs\model_datasets\model_dataset_*_v1.parquet
```

如果 `outputs\model_datasets` 中暂时没有文件，脚本会兼容读取旧位置 `outputs\model_dataset_*_v1.parquet`。

训练模型：

| 模型 | 目的 |
|---|---|
| `DummyClassifier` | 随机/基准模型，用来确认其他模型是否真的超过无信息基线 |
| `LogisticRegression` | 简单线性 baseline，便于观察特征是否有整体可分性 |
| `RandomForestClassifier` | 非线性树模型 baseline，适合处理缺失填补后的表格特征和非线性关系 |
| `HistGradientBoostingClassifier` | 梯度提升 baseline，作为更强的表格模型参考 |

交叉验证：

| 验证方式 | 说明 |
|---|---|
| `stratified_kfold` | 保持正负样本比例的常规交叉验证，适合观察模型上限 |
| `groupkfold_state` | 按 `state` 分组交叉验证，同一州不会同时出现在训练集和测试集，更接近跨地区泛化检验 |

输出指标：

```text

average_precision
balanced_accuracy
precision
recall
f1
tn / fp / fn / tp
```

主要输出：

```text

outputs\baseline_results\baseline_cv_summary_{dataset}.csv
outputs\baseline_results\baseline_group_errors_{dataset}.csv
outputs\baseline_results\baseline_feature_importance_{dataset}.csv
logs\10_train_baseline_summary.json
```

解释边界：

1. baseline 分数只能说明当前正负样本和现有特征有可分性，不能直接作为因果证据。
2. `stratified_kfold` 分数通常偏乐观；更应该优先看 `groupkfold_state`。
3. `baseline_feature_importance_*` 中的 Random Forest impurity importance 可用于初筛，但地球化学元素之间高度相关，单个特征排名不能直接解释为独立成因作用。
4. 当前主线已经接入地球化学1/2、NOAA 北美重力、CMMI 重力派生特征、DEM、断层、CMMI 地质图和 TerraClimate 气象特征。

## 6. 当前结果的解释边界

### 6.1 推荐作为全域基础特征

以下数据源在当前矿点集合上覆盖较好：

```text
geochem1_usgs_*
gravity_na_*
```

其中：

- `geochem1_usgs` 对全部矿点 50 km 内都有样点。
- `gravity_na` 对绝大多数矿点 10 km 内有网格点。

### 6.2 仅适用于美国西部子集

```text
geochem2_nure_*
```

NURE 再分析数据主要覆盖美国西部内陆。对 Alaska、Puerto Rico、美国东部州等，最近邻距离很远。建模时应配合：

```text
geochem2_nure_nearest_distance_km
geochem2_nure_count_25km
geochem2_nure_count_50km
```

如果距离过远或半径内点数为 0，不应解释为局地地球化学特征。

### 6.3 Alaska 专用数据暂不参与默认对齐

```text
gravity_alaska_freeair_*
gravity_alaska_station_*
```

`gravity_alaska_freeair` 对 Alaska 矿点覆盖较好；非 Alaska 矿点的最近邻距离很远，不应使用。

`gravity_alaska_station` 是测站数据，空间覆盖稀疏。建议使用时同时检查：

```text
gravity_alaska_station_nearest_distance_km
gravity_alaska_station_count_25km
gravity_alaska_station_count_50km
```

当前默认对齐已跳过 Alaska 专用重力字段，因此 `western_core` 和 `southwest_core` 的报告不再被这些 100% 缺失字段干扰。

### 6.4 Re 元素谨慎使用

Re 在原始数据中大量为未检出编码，清洗后缺失率很高。当前版本中：

```text
geochem1_usgs_Re_value_nearest
```

缺失率很高，不建议作为第一版核心模型变量。

### 6.5 DEM、断层和地质图覆盖边界

当前 DEM 下载范围是 western_core 所需瓦片，因此：

- `western_core`：DEM 覆盖 474/474，CMMI 地质图覆盖 474/474。
- `southwest_core`：DEM 覆盖 306/306，CMMI 地质图覆盖 306/306。
- `model_features_samples` 全域表：包含 Alaska、Puerto Rico 等点，DEM 和 CONUS 地质图不会全覆盖，这是预期结果。

断层数据覆盖美国、加拿大等区域；当前输出的是最近断层距离、不同半径内断层条数和断层长度。它不是影像特征，而是结构化空间特征，可以进入表格模型。

### 6.6 气象数据覆盖和解释边界

TerraClimate 是全球陆地网格气候数据。当前 `western_core` 和 `southwest_core` 中气象特征覆盖完整：

```text
western_core: 474 / 474
southwest_core: 306 / 306
```

全域 `model_features_samples` 中有少量气象月值缺失，缺失率约 0.37%，主要来自少数样本点落在 TerraClimate 无值网格上。主研究区不受影响。

当前气象特征是 1991-2020 多年平均气候态，不是矿床形成期气候，也不是矿点发现年份附近的天气。因此它适合表示现代地表环境、风化/侵蚀/水文背景，不应直接解释为斑岩铜成矿原因。

## 7. 后续可扩展方向

### 7.1 未检出信息建模

当前处理方式是将负浓度置为 `NaN`。后续可以保留未检出信息：

```text
{source}_{element}_nondetect_count_25km
{source}_{element}_nondetect_rate_25km
```

这对 Au、Re、W、Bi、Sb 等高未检出率元素尤其重要。

### 7.2 州级重力网格坐标转换

配置中已列出但未参与第一阶段：

```text
Nevada_Bouguer_Gravity_Grid\nevboug.xyz
Utah_Bouguer_Gravity_Grid\utahg.xyz
Idaho_Bouguer_Gravity_Grid\idahog.xyz
```

这些文件使用 `xindex,yindex,value`，需要读取头文件中的投影和网格参数后转换为经纬度，再纳入空间对齐。

### 7.3 气象时间序列和异常特征扩展

当前已经接入 TerraClimate 1991-2020 气候态。后续如果要加强气象部分，可以继续接入逐年或逐月时间序列，并按矿点提取：

```text
nearest
mean_5km / mean_10km / mean_25km / mean_50km
p95 / min / max
seasonal / annual summaries
长期均值、异常值、极端干旱/高温频率
```

对因果分析，应同时保留时间窗口、空间距离和样本覆盖指标，避免把远距离或稀疏数据误解为局地暴露。
