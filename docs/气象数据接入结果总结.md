## 4. 接入逻辑

对每个样本点：

1. 读取样本点 `latitude`、`longitude`。
2. 在 TerraClimate 网格中寻找最近的 `lat/lon` 网格点。
3. 提取 12 个月的气候态值。
4. 生成年度、暖季、冷季和季节性特征。

暖季定义：

```text
April - September
```

冷季定义：

```text
October - March
```

水量通量类变量使用年度/季节总量：

```text
ppt, aet, def, pet, q
```

状态类变量使用年度/季节均值：

```text
tmin, tmax, vap, vpd, ws, srad, soil, swe
```

## 9. 初步模型影响

以下为 `groupkfold_state` 下的主要结果。

### 9.1 Southwest Core

| 数据集 | 模型 | ROC-AUC | AP | Balanced Accuracy | F1 |
|---|---|---:|---:|---:|---:|
| `southwest_core_terrain_geo_v1` | Random Forest | 0.972 | 0.949 | 0.888 | 0.850 |
| `southwest_core_climate_geo_v1` | Random Forest | 0.973 | 0.951 | 0.851 | 0.790 |
| `southwest_core_full_v1` | Random Forest | 0.980 | 0.964 | 0.825 | 0.696 |
| `southwest_core_full_climate_v1` | Random Forest | 0.979 | 0.957 | 0.828 | 0.700 |

解释：

- 加入气象后，AUC 基本保持或略有变化。
- `climate_geo` 的 AUC/AP 略高于 `terrain_geo`，但 Balanced Accuracy 和 F1 下降。
- `full_climate` 与 `full` 接近，未形成明显大幅提升。

### 9.2 Western Core

| 数据集 | 模型 | ROC-AUC | AP | Balanced Accuracy | F1 |
|---|---|---:|---:|---:|---:|
| `western_core_terrain_geo_v1` | Random Forest | 0.947 | 0.885 | 0.855 | 0.801 |
| `western_core_climate_geo_v1` | Random Forest | 0.946 | 0.878 | 0.837 | 0.782 |
| `western_core_full_v1` | Random Forest | 0.955 | 0.903 | 0.861 | 0.808 |
| `western_core_full_climate_v1` | Random Forest | 0.956 | 0.918 | 0.828 | 0.774 |

解释：

- `western_core_full_climate_v1` 的 AUC/AP 与 `full` 接近，AP 略高。
- Balanced Accuracy 和 F1 有下降，说明默认阈值下分类稳定性没有提升。
- 气象特征目前更像辅助背景变量，不是主导预测信号。

当前相对靠前的气象特征包括：


总体判断：

```text
地球化学仍是主信号；
DEM 地形是稳定补充信号；
气象变量提供环境背景，但当前没有显著超过已有 full 模型；
气象更适合在后续因果推理中作为环境暴露、控制变量或异质性分析变量。
```

## 11. 解释边界

1. 当前气象数据是 1991-2020 现代气候态，不代表斑岩铜成矿时期气候。
2. 气象变量更适合解释现代地表环境、风化、侵蚀、水文背景、遥感/地球化学采样条件等。
3. 当前接入方式使用最近网格点，不是缓冲区平均。TerraClimate 分辨率约 1/24 度，主研究区样本可接受。
4. 如果后续做因果推理，气象变量应谨慎定义为“现代环境暴露”或“控制变量”，不要直接写成成矿因子。
