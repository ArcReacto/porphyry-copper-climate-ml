# 环境分组结果总结

本文档总结阶段 7 的气候/风化环境分组结果。环境分组用于后续“分 environment 做因果发现”和“寻找跨环境稳定信号”，不作为默认 baseline 模型的预测输入特征。

```text

```

```powershell

```

该脚本已经加入：

```text
run_pipeline.ps1
```

## 2. 分组依据

主要使用字段：

| 字段 | 含义 | 用途 |
|---|---|---|
| `climate_ppt_annual_sum` | 年降水量 | 水分输入 |
| `climate_pet_annual_sum` | 年潜在蒸散 | 干旱指数分母 |
| `climate_ppt_pet_ratio_annual` | 年降水 / 年潜在蒸散 | 核心干旱指数 |
| `climate_def_annual_sum` | 年气候水分亏缺 | 区分水分胁迫强弱 |
| `climate_tmean_annual_mean` | 年均温 | 判断寒冷环境 |
| `climate_swe_annual_mean` | 平均雪水当量 | 判断雪影响环境 |
| `terrain_relief_1000m_m` | 1 km 局部起伏 | 判断山地/高起伏 |
| `terrain_slope_deg` | 坡度 | 判断高起伏环境 |

主干旱指数：

```text
env_aridity_index_ppt_pet = climate_ppt_annual_sum / climate_pet_annual_sum
```

## 3. 阈值

干旱等级使用固定阈值：

| `env_aridity_class_unep` | 条件 |
|---|---|
| `hyper_arid` | P/PET < 0.05 |
| `arid` | 0.05 <= P/PET < 0.20 |
| `semi_arid` | 0.20 <= P/PET < 0.50 |
| `dry_subhumid` | 0.50 <= P/PET < 0.65 |
| `humid` | P/PET >= 0.65 |

为保证每个环境中样本数足够，后续因果发现优先使用更粗的 3 类气候分组：

```text
arid
semi_arid
subhumid_humid
```

地形和水分阈值来自 `western_core`：

| 阈值 | 数值 |
|---|---:|
| `terrain_relief_1000m_m` Q25 | 86.5 |
| `terrain_relief_1000m_m` Q75 | 391.75 |
| `terrain_slope_deg` Q25 | 3.264 |
| `terrain_slope_deg` Q75 | 19.171 |
| `climate_def_annual_sum` Q50 | 1071.5 |
| `climate_def_annual_sum` Q75 | 1376.975 |
| 雪影响阈值 `climate_swe_annual_mean` | >= 20 mm |
| 寒冷阈值 `climate_tmean_annual_mean` | <= 5 C |

## 5. Western Core 主分组结果

当前推荐后续因果发现优先使用：

```text
env_causal_group
```

| 环境组 | 样本数 | 正样本 | 负样本 | 解释 |
|---|---:|---:|---:|---|
| `arid_basin_or_range` | 190 | 52 | 138 | 干旱盆地/山间区 |
| `semi_arid_transition` | 161 | 51 | 110 | 半干旱过渡区 |
| `snow_influenced_mountain` | 77 | 53 | 24 | 雪影响高起伏山地区 |
| `subhumid_humid_mountain` | 46 | 2 | 44 | 相对湿润/山地区，正样本过少 |

阶段 8 做因果发现时，建议：

1. 主分析使用 `arid_basin_or_range`、`semi_arid_transition`、`snow_influenced_mountain`。
2. `subhumid_humid_mountain` 正样本只有 2 个，不适合单独训练因果发现模型，可作为外部参考或暂时合并/剔除。
3. 比较不同环境中稳定出现的地质、地球物理和地球化学信号，避免把只在单一气候环境中出现的表生异常误判为稳定控矿因素。
